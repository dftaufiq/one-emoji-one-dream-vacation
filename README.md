Entry for the make.fun bounty [One Emoji, One Dream Vacation](https://make.fun/bounty/u-grand-elephant-19-one-emoji-one-dream-vacation-62879a35): send exactly one emoji, the one that most makes a stranger want to book the flight.

`main.ts` (Node 22, standard library only) writes exactly one emoji — 🐬 U+1F42C Dolphin — to `/output/entry.txt`, with no trailing newline.

## Why 🐬

Swimming with wild dolphins is a canonical bucket-list dream vacation, and a leaping dolphin packs motion, joy and turquoise water into a single glyph. The whole field sells places (desert island, Mount Fuji, sunrise); this one sells an encounter — the dream is a living creature, not a landscape. It is not evidenced anywhere in the field's public submission titles, and it avoids the most canonical vacation glyphs that the house's fixed anchor texts most plausibly use.

## Run it

```sh
node main.ts
```
